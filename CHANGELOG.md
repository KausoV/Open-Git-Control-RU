# История локализации

## v3.2.3-ru.1

Первый выпуск независимой общественной локализации Open Git Control. Основа: официальный **v3.2.3**, коммит [`99e475f40a5497e971fa212014ffabe092c4ef78`](https://github.com/timbornemann/Open-Git-Control/commit/99e475f40a5497e971fa212014ffabe092c4ef78).

- Добавлен режим интерфейса **English + Russian (Русский)**: английский оригинал и русский перевод в скобках.
- Переведены каталоги интерфейса, встроенные подписи, нативные диалоги и контекстные меню; сохранены подстановки и технические значения.
- Добавлены двуязычные пояснения в подсказках и инструкциях. JSON-примеры, команды и пути не дублируются.
- Улучшен перенос длинных подписей кнопок и вкладок.
- Подготовлена переносимая сборка Windows x64 с профилем в `app/user-data` и запуском через CMD.
- Автоматическая установка официальных обновлений отключена по умолчанию для сохранения перевода.
- Опубликованы исходники, словари перевода и инструкция сборки с проверкой официальной Recovery либо её сборкой из Rust.
- Добавлена пошаговая инструкция по установке, подключению своего GitHub, первой отправке проекта и работе через Fork/Pull request.
- Исправлено отображение отказов Push: пояснение сервера и подробности правил GitHub сохраняются вместе со статусом ветки; чувствительные данные по-прежнему маскируются.

Содержимое заметок о выпусках и выбор языка результатов ИИ сохраняют исходные варианты `de`/`en`. Recovery включена без локализации. История самого приложения сохранена в исходном проекте и его [официальных выпусках](https://github.com/timbornemann/Open-Git-Control/releases).
